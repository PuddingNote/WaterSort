# GameDesign — WaterSort (색깔 정렬 퍼즐)

> 원본 기획서: `색깔정렬게임_기획서_범용형.md`(소재 무관 공통 로직) +
> `색깔정렬게임_기획서_물병버전.md`(물병 테마 특화). 이 문서는 그 둘을 이
> 프로젝트 기준으로 합쳐 정리한 요약이다. **기획서 문구와 실제로 구현하며
> 확정한 규칙이 달라지면, 기획서를 고치는 대신 이 문서에 "왜 다르게
> 확정했는지"를 추가해 나간다** (재사용 노트 9장 원칙).

## 한 줄 컨셉
여러 병에 뒤섞여 담긴 색깔 물을 병 사이로 부어 옮겨, 한 병에 한 가지 색만
남으면 클리어되는 캐주얼 퍼즐 (Water Sort Puzzle류).

## 핵심 로직 (소재 무관 — Core/Solver에 구현될 것)
- 이동 조건: 출발 병에 물 1칸 이상, 도착 병에 여유 슬롯 1칸 이상, 도착 병이
  비어있거나 최상단 색이 출발 병 최상단 색과 동일.
- 이동량: 출발 병 최상단부터 연속된 동일 색을, 도착 병 여유 슬롯이 허용하는
  만큼만 이동.
- 클리어: 사용 중인 모든 병이 "완전히 비어있음" 또는 "한 색으로 가득 참" 중 하나.
- 실패(게임오버) 조건 없음 — 교착 상태만 감지해 힌트/초기화/병 추가로 유도.
- 라운드 생성은 **완전 무작위 배분**: 전체 유닛(색상 수×슬롯 수)을 진짜로
  섞어서 병에 나눠 담고, 생성 직후 솔버로 실제로 풀리는지 검증해 안 풀리면
  재시도한다(처음엔 "역방향 생성"으로 항상 풀림을 수학적으로 보장하려 했으나,
  덩어리 단위로만 섞여서 실제로는 색이 크게 뭉친 시시한 라운드가 나왔다 —
  `docs/Architecture.md` "라운드 생성 방식 전면 교체" 참고).
- 난이도는 병 개수 하나로 판단하지 않는다. 실측 결과 **여유 막대 수는
  "적을수록 어렵다"가 아니라 일정 수 밑으로는 아예 안 풀리는 문턱값**이었다
  (테마 최소치 밑으로는 내리지 않는다). 라운드 진행에 따른 난이도는 색상
  수×슬롯 수(총 유닛 수)가 전담하고, 실제 난이도는 `RoundBuilder`가 돌려주는
  실측 클리어 수(`SolutionMoveCount`)로 직접 확인한다.

## 물병 테마 특화 (Presentation — UI 계층 안에 위치)
- 배치: 최대 2줄 × 줄당 6개 = 최대 12병. 슬롯 수는 라운드당 4~9칸(라운드 내
  전체 병이 동일 슬롯 수).
- 색상 팔레트 9종 고정(레드/그린/블루/옐로우/핑크/퍼플/그레이/스카이블루/
  스카이그린). 라운드는 이 중 일부만 사용.
- 붓기(Tilt) 애니메이션(소요 시간 약 1초, 2026-08-25 확정), 도착 병 실시간
  차오름, 여러 층 동시 이동은 하나의 흐름으로, 무효 이동 시 살짝 기울었다
  복귀 + 진동. 사운드는 이동이 끝나는 마지막 붓기 순간에만 1회 재생(층별
  반복 재생 안 함, 2026-08-25 확정).
- 색맹 접근성: 유사 색상 쌍(블루/스카이블루, 그린/스카이그린) 명도·채도 차이
  확보. 패턴 표시 옵션은 도입하지 않기로 확정(2026-08-25).

## 필수 기능 (공통 정책, 소재 무관 로직 + 물 연출)
| 기능 | 정책 |
|---|---|
| 초기화(Reset) | 라운드 시작 상태로 즉시 복원, 이동/undo 이력 초기화. 확인 팝업 권장 |
| 실행취소(Undo) | 스택 기반, 라운드 시작 지점까지 연속 가능. 물 버전은 붓기 역재생 연출 |
| 힌트 | 무료 2회, 5라운드 클리어마다 1회 충전, 이후 보상형 광고 1회 = 1회 사용. 솔버가 최적 다음 수 계산 후 자동 실행. 최대 보유 5개(그 이상은 충전 안 됨, 2026-08-25 확정) |
| 병 추가 | 광고 1회 = 병 총 슬롯의 20%씩 순차 생성(라운드마다 다른 slotCount에 대한 상대 비율로 계산, 2026-08-25 확정. 완성 전 사용 가능 여부는 여전히 TBD). 매 라운드 시작 시 사용 횟수 초기화 |
| 라운드 전면광고 | 3라운드 클리어마다 1회, 닫으면 자동 다음 라운드 |
| 광고 미시청/로드 실패 | 힌트 충전·병 추가 기능을 그 자리에서 비활성화(재화 등 대체 지급 없음). 2026-08-25 확정 |

## UI 배치 (게임 화면)
좌상단 뒤로가기 · 우상단 설정 · 중앙 병 배치 영역 · 좌하단 실행취소+초기화 ·
우하단 힌트+병추가. 타이틀 화면은 중앙 상단 로고 + 시작 버튼 위 부제 + 좌상단
설정 + 시작/종료 버튼.

## 데이터 구조 (참고용 — 실제 필드명은 구현 시 확정)
```json
{
  "roundId": 45,
  "difficultyScore": 62,
  "bottleSlotCount": 6,
  "colorCount": 5,
  "emptyBottleCount": 2,
  "bottles": [
    { "id": 0, "waterLayers": ["yellow", "skyblue", "green"] }
  ]
}
```
`waterLayers` 마지막 값이 병 입구(최상단, 이동 가능한 물).

- [x] ~~실행취소와 병 추가의 상호작용~~ — 확정(2026-08-25): 병 추가는 광고를
      소비해서 얻은 아이템 개념이라 Undo 대상에서 절대 제외(Undo로 방금 만든
      병이 다시 사라지는 일은 없어야 함). 단 그 병에 이미 부어 넣은 물의
      "이동"은 여느 이동과 동일하게 평소처럼 Undo 가능 — Undo가 되돌리는 건
      항상 물 이동뿐, 병의 존재 자체는 절대 되돌리지 않는다.
- [x] ~~광고 미시청/로드 실패 시 대체 처리~~ — 확정(2026-08-25): 힌트 충전·
      병 추가 기능을 그 자리에서 비활성화. 재화 등 대체 지급 없음.

  200→50→100→200으로 반복 조정해 온 것 자체가 그 체감 검증 과정이다
  (`docs/Architecture.md` "라운드 생성 방식 전면 교체" 참고). 완료된 To-Do가
  아니라 계속되는 튜닝 작업이라 체크박스에서 제외.

      막지 않는다. 다른 병 애니메이션이 재생 중이어도 새로 탭한 이동은 그냥
      바로 시작(동시에 여러 병이 붓는 애니메이션이 겹쳐도 무방). 사운드는

      애니메이션일수록 그 뒤에 깔린다.
